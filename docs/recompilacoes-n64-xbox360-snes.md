# ⚡ Nintendo 64, SNES, NES, GBA, GBC, NDS, 3DS, Mega Drive, Dreamcast & Saturn (Recompilações & Ports Nativos)

Este guia reúne **todos os projetos de Recompilação Estática e Ports Nativos** de **Nintendo 64 (`N64Recomp` + `RT64`), Super Nintendo (`snesrecomp` / `snesrev`), NES (`nesrecomp`), Game Boy Advance (`gbarecomp` / `pret`), Game Boy Color, Nintendo DS (`ndsrecomp`), Nintendo 3DS (`TriAevum`), Mega Drive (`segagenesisrecomp` / RSDK), Dreamcast (`dcrecomp`) e Sega Saturn (`SaturnRecomp` / `Azel`)**, com status de **Tradução PT-BR**.

> 💡 Para os ports N64 da equipe **Harbour Masters (`libultraship`)** (*Ship of Harkinian*, *2Ship2Harkinian*, *Starship*, *SpaghettiKart*, *Ghostship*, *Lighthouse*, *PaperBoat*), consulte também [`docs/harbourmasters-zelda-mario-starfox.md`](harbourmasters-zelda-mario-starfox.md).
