# 🎮 PortsPC — O Catálogo Definitivo de Ports Nativos, Recompilações Estáticas e Descompilações para PC (com Guia PT-BR 🇧🇷)

Bem-vindo ao **PortsPC**! Este repositório é um catálogo **100% atualizado (Outubro de 2026)**, livre, comunitário e sem burocracia com **mais de 230 Ports Nativos de Console para PC, Recompilações Estáticas (`PS2Recomp`, `XenonRecomp`, `ReXGlue`, `N64Recomp`, `DolRecomp`, `PSXRecomp`, `snesrecomp`), Descompilações (`libultraship`, `OpenGOAL`, `snesrev`), Source Ports e Remakes**, focado em **Windows** (e **Linux / Steam Deck**) e com mapeamento completo de **Traduções e Dublagens em Português Brasileiro (PT-BR)**.

> 💡 **Economia Inteligente de Espaço em Disco:**
> Este repositório ocupa **menos de 2 MB** no seu HD/SSD! Em vez de obrigar você a clonar ou compilar centenas de gigabytes, incluímos o **Instalador Sob Demanda (`Instalar-Ports.bat`)**: você escolhe no menu apenas o jogo que quer jogar agora, ele baixa a versão oficial pré-compilada direto do GitHub para `F:\Jogos\PortsPC\<Jogo>`, extrai e **apaga o `.zip` temporário imediatamente**.

## 🚀 Como Usar o Instalador Sob Demanda (Windows)

Não quer caçar links no GitHub nem lotar seu disco?
1. Dê dois cliques em **`Instalar-Ports.bat`** (ou rode `powershell -ExecutionPolicy Bypass -File .\scripts\portspc.ps1`).
2. Escolha a categoria ou digite o número do port desejado (mais de **100 projetos configurados** no [`catalog.json`](catalog.json)!).
3. O script baixa apenas o executável oficial mais recente para `F:\Jogos\PortsPC\<id-do-port>`, extrai os arquivos, **remove o `.zip` temporário imediatamente** para poupar espaço no seu disco `F:` e exibe na tela exatamente qual ROM/ISO você precisa e **como ativar o PT-BR**!

## 📊 Legenda de Suporte a Português Brasileiro (PT-BR)

* 🟢 **PT-BR Nativo / Oficial:** Já incluso no próprio port ou no disco oficial (muitos com **Dublagem Brasileira Oficial!**).
* 🧩 **Mod PT-BR no Port:** Arquivo leve (`.otr`, `.o2r`, `.nrm` ou via Mod Manager) colocado na pasta `mods/` sem alterar a ISO/ROM.
* 🛠️ **Patch na ISO/ROM:** Funciona aplicando a tradução/dublagem brasileira (`.xdelta`, `.bps`, `.ips`, `.pak`) na ISO ou ROM original.
* ⚪ **Sem Tradução / Arcade:** Jogos de corrida/luta com pouco texto ou projetos ainda sem patch PT-BR.
